## Source facts that bind every crop

| Fact | Value | Consequence |
|---|---|---|
| All six clips | 1920×1080, 24 fps, H.264, audio stripped | Re-encode, never upscale |
| Veo watermark (four-point star) | bottom-right, roughly x 1700–1770, y 870–930 of 1920×1080, baked into every frame of every clip (`qa/report.md`) | **Every crop window must satisfy `x + width ≤ 1620`.** Landscape 3:2 = `crop=1620:1080:0:0`. Portrait 3:4 = `crop=810:1080:405:0`. Square = `crop=1080:1080:270:0`. |
| `still_hero.jpg` | 1600×900, no watermark | The only clean 16:9 — OG image and the beef still |
| Delivery ceiling | 720 lines desktop, 480 lines mobile, ≤ 8 s loops, no audio | `-crf 24` desktop / `-crf 27` mobile, `-movflags +faststart`, `-pix_fmt yuv420p`, `-an` |
| Hallucinated frames (`notes.md`) | leg1 frames 65–120 (global) = 4.3 s–8.0 s of leg1 | leg1 trimmed to 0–4.2 s |

Encode recipe (desktop 3:2, from any clip):

```
ffmpeg -i IN.mp4 -ss START -t DUR -an -vf "crop=1620:1080:0:0,scale=1080:720:flags=lanczos" \
  -c:v libx264 -preset slow -crf 24 -pix_fmt yuv420p -movflags +faststart OUT.720.mp4
ffmpeg -i IN.mp4 -ss START -t DUR -an -vf "crop=1620:1080:0:0,scale=720:480:flags=lanczos" \
  -c:v libx264 -preset slow -crf 27 -pix_fmt yuv420p -movflags +faststart OUT.480.mp4
ffmpeg -i OUT.720.mp4 -frames:v 1 -q:v 2 OUT.poster.jpg   # then sharp → .webp q80
```

Optional second source per clip for smaller payload: `-c:v libsvtav1 -crf 38` → `.webm`,
served first in `<source>` order; keep H.264 as the guaranteed fallback.

  > warm single light as the reference. Minimal plating, a few flakes of salt. No hands, no
  > cutlery, no text.

  > Macro of the ember bed only: glowing oak coals, grey ash edges, a few sparks, pitch-black
