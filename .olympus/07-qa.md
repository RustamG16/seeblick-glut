# 07 — Visual QA (author pass, cycle 1)

## Environment

- Build: `npm run build` → `astro preview` at `http://localhost:4321/seeblick-glut/` (production base path).
- Browsers: Claude desktop browser pane (Chromium) with viewport emulation; Chrome headless shell
  (Remotion's, v from `remotion/node_modules/.remotion`) via CDP for evidence (`scripts/shoot.mjs`).
- Viewports: 1440×900, 390×844 (plus 600/900/1280 breakpoints checked in CSS against the ramp).
- Evidence: `.olympus/screenshots/{before,after}-{1440,390}-{top,full}.jpg`. Full-page captures
  repeat the fixed header at the bottom — a capture artefact of `captureBeyondViewport`, not the page.
- Limitation: the browser pane was hidden for part of the run; hidden pages throttle
  `requestAnimationFrame` and IntersectionObserver, so **frame-time in §4 and LCP were not
  measurable here**. They are listed as targets, not results.
